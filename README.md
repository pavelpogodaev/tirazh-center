# Центр спусков и тиражей (Web Prod)

Профессиональный веб-сервис для специалистов допечатной подготовки (препресс) и технологов флексо-, офсетной и цифровой печати (HP Indigo, Офсет, Флексо, Хаотян, Ригуан).

## Возможности веб-версии
- **6 алгоритмов формирования спусков**:
  1. *Макс. оптимизация* — умный поиск баланса между стоимостью перетиража и экономией приладок (150 м OS / 15 м HP).
  2. *Делители ручьёв* — строгая кратность ручьям печатной машины.
  3. *Кратное слияние* — пропорциональное объединение тиражей.
  4. *Под размотку* — учет концовок бобин и безотходной перемотки.
  5. *Как в CRM* — точное воспроизведение спусков из заказа.
  6. *Каждый отдельно* — базовый раздельный спуск.
- **Интеграция с CRM и Excel**: мгновенный парсинг таблиц, подготовка данных в 3, 4 и 5 колонок.
- **Экспорт для Illustrator**: автоматическое формирование названий монтажек + прямая загрузка скрипта `Применить_имена_монтажек.jsx`.
- **Сбор отзывов и диагностика**: встроенная форма отправки пожеланий и баг-репортов с техническим дампом заказа на почту разработчика (`pavelpogodaev@gmail.com`).
- **PWA (Progressive Web App)**: возможность установки на рабочий стол как отдельного приложения через Google Chrome, Edge или Safari.

## Развертывание на Cloudflare Pages
1. Репозиторий подключен к GitHub: `pavelpogodaev/tirazh-center`.
2. В панели [Cloudflare Dashboard](https://dash.cloudflare.com/) перейдите в **Workers & Pages** -> **Create application** -> **Pages** -> **Connect to Git**.
3. Выберите репозиторий `tirazh-center`.
4. Настройки сборки:
   - **Framework preset**: None
   - **Build command**: (оставить пустым)
   - **Build output directory**: `/` (корень)
5. Нажмите **Save and Deploy**. Проект готов и обновляется автоматически при каждом коммите!
